# Lens Ruler

Мобильный веб-прототип интерактивной линейки страниц.

## Открыть на iPhone в той же Wi‑Fi сети

1. На компьютере из папки проекта запустить `npm install` (при первом запуске), затем `npm run dev -- --host 0.0.0.0`.
2. Оставить терминал с запущенным сервером открытым.
3. В Safari на iPhone открыть сетевой адрес, который Vite напечатает в строке `Network`, например `http://192.168.0.77:5173/`.

Телефон и компьютер должны быть в одной сети. Адрес действует, пока работает dev-сервер; это тестовый доступ по локальной сети.

## Проверка и сборка

- `npm run dev` — открыть прототип на этом компьютере.
- `npm run build` — собрать статические файлы в `dist/`.
- `npm run lint` — проверить исходники.

## Публикация на GitHub Pages

Репозиторий `lens-ruler` можно опубликовать как публичный проект, а сайт развернуть через GitHub Pages:

1. Создайте на GitHub публичный репозиторий `lens-ruler`.
2. Отправьте в него исходники проекта из ветки `main`.
3. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в разделе **Build and deployment**.
4. Workflow `.github/workflows/deploy.yml` соберёт приложение и опубликует содержимое `dist/` при каждом push в `main`.

Публичная ссылка будет `https://<ваш-логин>.github.io/lens-ruler/`. Для загрузки шрифта Doto браузеру нужен доступ к интернету.
